# 미국 자동매매 위험 UI 모의 검증

`node scripts/isolated-us-risk.cjs` → `http://127.0.0.1:13110`

실제 KiwoomUsAutoTrade/RiskPanel과 앱 전역 CSS를 렌더링한다. 화면 상단에서 최초 활성, 정상, 입출금 검토, 청산 잠금, 오래된 평가, API 실패, 계좌 동기화 불명을 선택하면 컴포넌트를 다시 마운트한다. 정책 활성/입출금 반영/매수 버튼은 메모리 mock만 변경한다. 이 하네스는 서버 정책·입출금 계산·실제 주문 동작을 검증하지 않는다.

- 프로세스 환경은 시스템 허용목록만 상속하고 Vue CLI `.env*` 로딩을 비활성화한다. 운영 vue.config.js와 앱 라우터/인증 초기화는 실행하지 않는다.
- webpack 모듈 교체로 `@/axios`와 `axios`는 전용 메모리 mock만 사용한다. 알 수 없는 API는 오류를 낸다. 프록시는 없다.
- CSP `connect-src 'none'`, fetch/XHR/WebSocket 차단, 무연결 EventSource로 외부 API 접근을 막는다. 페이지 링크 이동도 취소한다. 외부 폰트/CDN은 사용하지 않는다.
- 13110은 127.0.0.1에만 바인딩한다. 포트 점유 시 실행을 실패시킨다.
- 390px 컨테이너 버튼은 폭 제한 확인용이다. 실제 모바일 미디어쿼리는 브라우저 뷰포트를 390px로 설정해서 검증한다.
- 종료: 실행 터미널 Ctrl+C. 출력된 launcher/worker PID만 확인해서 종료하며 다른 Node 프로세스를 종료하지 않는다.

시각검증 대상: 데스크톱과 390px 화면에서 가로 넘침, 자금요약 노출, 최초 두 동의, 입출금 확인 대기/0원 확인, 손실잠금, 90초 지난 평가의 매수차단, API 실패 및 설정창.
