# TEAM-14 상시 모의매매 준비

- 요청: 실주문 없는 모의경로/원장, 시세·장시간·비용, 장애·재시작·중복방지, 비교화면 네 가지 모두 준비.
- 상태: 구현 및 HTTP·재시작 검증 완료, 최종 브라우저 검증 대기. 운영 적용·실주문·push는 범위 밖. 기존 TEAM10~13 미커밋 변경 보존. 사용자 목표 재확인에 따라 실계좌 준비 검토는 TEAM-15에서 진행한다.
- 기획/총괄: 계약·격리 런처·통합/브라우저 검증·기록. BE개발: 신규 paper도메인. FE디자인/개발: 별도 모의매매 탭/패널. 독립검증: 경계 및 상태/복구 검증.

## 계약

관리자 전용 `/api/us-paper/sessions` 생성/목록/개별조회/start/stop/poll. 세션별 가상 USD현금·SPY정수주·체결·평가·이벤트 원장을 유지한다. 기본 가상자금USD10,000, 편도수수료5bp/슬리피지5bp 고정. STOPPED재개는 동일원장/고점을 유지하며 HARD10%는 재개/리셋불가. 새세션은 명시생성하며 이전기록을삭제하지않는다.

실험전략은 SPY 완료일봉SMA200에 따른 최대80%가상비중으로고정. 현금99% 비용포함한도·공매도/차입금지. 신규전략의초과수익검증완료를주장하지않는다. 공개시세는지연될수있으며 SPY가격수익률을 S&P500 ETF대용비교로명확히표시한다(배당포함총수익지수와다름).

## 격리와 사용 환경

- 기존실주문서비스/계좌키/운영DB/전체부팅runner를사용하지않는 별도Spring진입점. paper도메인만 명시등록. 기본제품설정에서는paper/scheduler비활성.
- 로컬 API 127.0.0.1:13220, 전용Vue화면127.0.0.1:13120. 동일출처paper경로만프록시. 서버간랜덤토큰은브라우저번들에포함하지않는다.
- H2파일DB와프로세스잠금, 환경변수allowlist, 고정설정만읽고.env미사용. 실제공개시세모드와시험fixture모드 DB분리.
- 실제주문어댑터없음. 시세외부GET호스트/경로고정, redirect금지/timeout. stale/미완료/휴장시가상체결금지.
