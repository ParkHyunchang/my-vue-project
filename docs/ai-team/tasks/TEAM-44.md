# TEAM-44 자동매매 운영 정보 우선 정리

- 요청: 운영 상태/차단 이유 → 보유·미체결·최근 체결 우선 → 중지 범위 → 오늘 기록 → 중요한 알림까지 전부 개선. 메뉴 이름 자동매매, 정리 완료된 수기 삭제 도구 숨김 포함.
- TEAM-43 미커밋 변경을 그대로 이어서 작업한다. 기존 자동매매 전략/주문 허용 조건/실행 루프는 변경하지 않는다.
- design: 국내 KiwoomAutoTrade/KiwoomStrategyPanel, planning: 미국 KiwoomUsAutoTrade, verification: 회귀 테스트와 독립 검토. 총괄: 공통 주의 알림·메뉴 표기·삭제 도구 정리·통합 검증.
- 화면의 조회된 데이터만 근거로 표시한다. 일부 기록 조회를 하루 전체 집계로 표현하지 않는다. 없는 주문·체결 필드를 추정하지 않는다.
- 알림은 화면 내 표시와 사용자가 켜는 브라우저 알림이다. 선택한 시장 화면이 열려 있는 동안에만 동작하며 서버 백그라운드 푸시/문자/메신저 전송은 범위에 포함하지 않는다. 운영 실계좌 호출·실주문·설정 변경 없이 합성 검증한다.

## 구현 결과

1. 국내·미국 운영 상태와 신규 매수 차단 이유를 상단 표시한다. WebSocket 연결과 REST 주문 가능 여부를 구분하고 미조회·조회 실패를 정상 0으로 표시하지 않는다.
2. 보유 → 진행·미확인 주문/체결 확인 → 오늘 기록 순서로 배치하고 후보·전략 설정은 접었다. 미국은 기존 proposals 읽기 API를 추가 사용한다.
3. 국내 완전 중지의 미체결 매수·매도 취소 요청과 미국 신규 매수 중지 후 청산 감시·주문 동기화 지속을 설명한다. 기존 주문 handler·매매 조건은 변경하지 않았다.
4. KST 오늘 기록과 최근 로그의 이벤트 건수를 표시한다. 국내 최근 50개 판단/20개 감사 기록, 미국 최근 50개 주문/300개 로그 범위이며 전체 일일 합계가 아니다. 국내 체결 시각은 제공되지 않아 오늘 체결 건수로 추정하지 않는다. 오프셋 없는 시각은 배포 설정의 Asia/Seoul 기준으로 해석한다. 응답 직후 시계를 갱신하여 새 기록의 초기 누락을 방지한다.
5. 주문 미확인·연결 확인·위험 제한 알림과 선택형 기기 알림을 구현했다. 동일 활성 경고의 반복 전송을 방지하고 권한 거절/미지원 시 화면 안내를 유지한다. OS 알림에는 종목·금액을 넣지 않는다. service worker는 알림 클릭 처리만 하며 앱 요청을 가로채지 않는다.
6. 기본 메뉴 이름은 자동매매로 통일하되 사용자가 별도로 정한 이름은 유지한다. 수기 기록 0건 확인 후 정리 도구를 해당 사용자 브라우저 세션에서 숨길 수 있다.
