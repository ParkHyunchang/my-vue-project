# TEAM-21 공개 일봉으로 검증 가능한 전략 비교

- 시작일: 2026-11-19. 상태: 비교·독립 검증 완료, 운영 채택 보류.
- 사용자 목표: 확보 가능한 실제 시장자료로 종목 선택 방식을 바꾸어 S&P 500 대비 수익률을 비교한다. 현금 한도와 계좌 고점 대비 10% 중단 규칙을 유지하며 운영에 적용하지 않는다.
- 운영 경계: 오프라인 Python 연구 파일·문서만 추가한다. 서버·실계좌·키·DB·운영 설정 접근, 주문 전송, push, 배포 없음. TEAM-19 Java 장중 주문 재생과 별개의 일봉 전략 연구이며 기존 운영 로직의 성과라고 표시하지 않는다.

## 역할과 소유 파일

- 총괄: 설계·자료·코드 해시 동결 후 실제 성과 실행, 결과 통합 및 현황 갱신.
- 자료 개발: BE `tools/team21_fetch.py`, `team21_data_test.py`, `team21_data/` 공개 원문·변환 자료·명세.
- 전략 개발: BE `tools/team21_research.py`, `team21_test.py` 주문·체결·현금·보유·위험 원장.
- 독립 기획·검증: 이 문서, BE `tools/team21_audit.py`, `team21_audit_test.py` 및 독립 재계산.
- 화면/API 변경이 없어 디자인·브라우저 범위는 없다. 이전 변경을 보존한다.

## 성과 실행 전 고정한 30개 비교

| 구분 | 사전 고정 내용 |
|---|---|
| 전략 1 | SPY SMA200 추세 대조군: 완료 일봉 조정종가가 200일 평균보다 클 때 SPY 보유 |
| 전략 2 | 고정 8개 섹터 ETF 중 조정종가 SMA200 상회·126거래일 모멘텀 양수인 상위 1개 |
| 전략 3 | 같은 필터·순위 상위 3개 동일 비중; 통과 종목이 부족하면 해당 슬롯은 현금 |
| 후보 ETF | XLB, XLE, XLI, XLK, XLP, XLU, XLV, XLY. 동률은 종목 코드순. XLF는 자료 확보 후 성과 실행 전 기업분할 처리 문제로 제외 |
| 구간 | 2008–2017 / 2018–2023 / 2024–2025 / 2026 YTD / 2008–최신 연속 구간 |
| 비용 | 편도 총 10bps 및 25bps, 수수료·슬리피지에 절반씩 배분. 각 비용별 3전략×5구간=15회, 총30회 |
| 자금 | 구간별 10,000 USD 현금 시작; 정수 주식; 레버리지·음수 현금 없음 |
| 위험 예산 | 총 투자 목표 `min(0.8, 2 × max(0, equity − 0.9 × peak) / equity)` |
| 현금 제한 | 매수 시 실제 결제된 현금의 99% 이내; 매도 대금은 다음 거래일 이후에만 매수 자금 사용 |
| 중단 | 전 계좌 고점 대비 10% 이상 하락 시 영구 매수 잠금·청산. 시가/종가 관측, 연속 구간에서 고점·잠금 초기화 없음 |

- 평가 첫 완료 종가 및 새로운 월의 첫 완료 종가에 종목을 재선정한다. 완료 종가 신호를 다음 거래일 시가에만 실행한다. 매일 SMA200·양수126일 모멘텀 자격 상실 시 퇴출하고 위험 예산에 맞춰 매일 비중을 조정한다(SPY 대조군은 SMA200만 적용). 배당은 배당락일 보유분의 채권으로 평가하지만 지급일 미확보 때문에 끝까지 주문 가능 현금에 넣지 않는다. 상세 실행 시점·분할·결제 가정은 실행 전 동결한 엔진 메타데이터를 함께 보존한다.
- 성과 실행 전 변경: XLF 2016년 부동산 사업 분리는 단순 주식분할이 아니므로 명목 가격·분배 수량을 입증하지 못한 상태에서 보유 원장에 넣지 않는다. 수집은 유지하되 실행 후보를 8개로 줄였다. 전략·구간·비용 30개 비교 수는 동일하다.
- 위 위험식은 `equity ≤ peak`이므로 실제 목표 총비중 상한이 20%다. 80% 상한은 도달하지 않는다. 이를 성과 확인 전에 확인했으며 성과를 높이기 위한 위험 모수 변경은 하지 않는다.
- 매도대금 T+1 모델을 전체 기간에 통일한다. 과거 실제 T+3/T+2 결제 규정의 재현이 아니다. 배당은 지급일까지 현금으로 풀리지 않는 것이 아니라 이 연구에서는 지급일 미확보로 끝까지 채권에 머문다. 수익률은 매매 비용 차감 후·배당 원천세/양도세/환전 비용 차감 전 USD 기준이다.
- 자료는 2006년부터 준비해 SMA200·126일 신호를 예열한다. 2026년 마지막 완료 미국 거래일은 공급 자료로 확인하고 모든 후보·벤치마크에 공통 날짜를 사용한다.
- 실행 후 모수 변경·유리한 기간만 선택·추가 탐색은 하지 않는다. 결함 수정 시 이유와 변경 해시를 남기고 30개 전체를 재실행한다.
- 가격 비교는 S&P 500 총수익 지수 `^SP500TR`를 우선하며 SPY도 참고 대조한다. 분배금이 포함된 전략 자산과 가격지수만 비교하지 않는다. 시작·종료 시점, 지수 비용 미차감 등의 차이는 결과에 명시한다.

## 원장·자료 검증 완료 기준

1. 공개 원문·변환 CSV·수집 명세 SHA256 보존, 날짜·가격·기업행사·조정 기준 및 공통 범위 검사.
2. 주문 이전 완료 종가만으로 종목·모멘텀·SMA·목표 비중 재계산. 시가 주문에 당일 종가를 사용하지 않음.
3. 독립 감사가 매일 매수·매도 체결가/비용/정수 수량, 현금, 보유, 미결제 대금, 배당채권, 평가액을 원자료에서 재계산.
4. 현금99%·음수 현금 방지, 계좌 고점 연속성, 10% 잠금 지속, 목표 위험 예산의 인과성 확인.
5. 30개 결과 모두 공개: 순수익률, 동일 기간 지수 수익률과 차이, 최대 낙폭, 거래수, 투자 비중, 중단일. 무거래·장기 현금 상태도 누락하지 않음.
6. 실제 자료 비교 전에 엔진·감사기 합성 단위검사 및 설계/자료/코드 해시 동결. 결과 감사를 별도 파일로 보존.

## 해석의 제한

- 과거 TEAM 연구에서 이미 본 기간이므로 신규 독립 홀드아웃이 아니다. 이번 사전 고정은 결과를 보고 모수를 조정하는 것을 줄이지만 과최적화 위험을 제거하지 않는다.
- 현존하는 고정 8개 섹터 ETF의 비교다. 당시 전체 개별주식 모집단을 재구성한 것이 아니며 개별주식 생존편향 제거를 주장하지 않는다. 후발 섹터 ETF와 XLF는 포함하지 않는다.
- 공개 공급자의 사후 조정자료와 일봉 시가 체결 가정을 사용한다. 실제 장중 스프레드·유동성·부분 체결·주문 지연은 재현하지 않는다. 조정종가는 신호용이며 배당을 다시 이중 계산하지 않는다.
- 10%는 차단 발동 기준이다. 야간 갭·장중 경로 미관측·체결 비용 때문에 실제 최대 손실 10%를 보장하지 못한다. 초과 발생은 그대로 실패/제한으로 보고한다.
- 연구는 새 계좌의 현금 시작이다. 사용자 기존 보유 종목·평균단가·환율·세금·실제 계좌 결제 조건은 성과에 반영하지 않는다. 기존 보유 관리 요구를 운영에서 제거하지 않는다.
- 결과가 지수보다 좋아도 운영 채택/실가동 준비 완료가 아니다. 기존 서비스 통합 및 기존 보유·부분 체결·재시작 검증이 별도로 필요하다.

## 원자료 해석 근거

- 발행사 [섹터 ETF 목록](https://www.ssga.com/us/en/individual/capabilities/equities/sector-investing/sector-and-industry-etfs)에서 고정 후보의 섹터 상품 분류를 확인한다. 현재 상품군은 11개이지만 이번 연구는 장기 자료를 가진 9개를 수집하고 XLF를 뺀 8개만 비교한다.
- 발행사 [분할 공지](https://investors.statestreet.com/investor-news-events/press-releases/news-details/2025/State-Street-Investment-Management-Announces-Share-Splits-for-Five-Select-Sector-SPDR-ETFs/default.aspx)에 따르면 XLB·XLE·XLK·XLU·XLY의 2:1 분할 후 거래는 2025-12-05부터다. 정수 주문의 명목 가격을 복원하고 보유 수량에 분할을 반영해야 한다.
