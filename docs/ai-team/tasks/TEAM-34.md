## 기획

- 대상: 공개 포트폴리오 방문자 및 개인 생활·자산 도구 사용자.
- 범위: 공통 색상·서체·간격·컨트롤·내비게이션·홈 및 도메인 화면의 시각 일관성, 반응형.
- 제외: API/DB 계약 변경, 금융 계산·주문 동작 변경, 운영 배포.
- AC-1: 홈과 공통 메뉴/폼/카드/모달에 일관된 새 디자인을 적용한다.
- AC-2: 기존 기능, 권한, 조회·저장 동작과 로딩/오류/빈 상태를 보존한다.
- AC-3: 데스크톱과 모바일 대표 화면에서 가독성·가로 넘침·포커스를 확인한다.
- AC-4: 격리 테스트·lint 및 실제 diff 독립 검토 결과를 기록한다.

- 격리 Jest: 14 suites / 152 tests 통과.
- 전체 lint --no-fix 통과. 이후 수정된 Vue/JS 파일도 대상 lint 통과.
- 실제 Vue 개발 컴파일 성공. 기존 admin.css의 flex `end` 호환성 경고 및 Browserslist 오래된 데이터 안내.

## 인수인계 및 운영

- 운영 미배포. 커밋/push 하지 않음. 백엔드 작업 트리 변경 없음.
- 적용 범위: 공통 테마와 셸은 전체 화면에 적용, 홈/주요 도메인 레이아웃 정리.
- 미검증: 모든 도메인 하위 탭·모달의 전수 E2E, 실제 인증·외부 서비스·운영 웹폰트/CDN. 게스트 검증 403 대역은 기존 인증401 리디렉션 이슈를 검증한 것이 아님.
- 후속: 실제 콘텐츠/외부 폰트가 있는 운영 반영 전 확인은 별도. 이 작업에서 API/DB 변경이나 배포 순서 의존성 없음.
