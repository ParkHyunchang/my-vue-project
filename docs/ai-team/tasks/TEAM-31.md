## 완료 기준

1. 역사 승인 실패와 실계좌 코드 지원을 구분하고 관찰 후보를 명시한다.
2. 사용자 현금 규모와 기존 보유를 Java 주문계획 테스트에 포함한다. 합성가격을 실제 평가액으로 표현하지 않는다.
3. 기존 전진 관찰 일수와 체결 수를 확인하고, 과거 실패를60일 기다리면 해결된다고 표현하지 않는다.
4. 격리 검사 결과와 실행 제약을 기록한다. 새 전략 승인·실계좌 기동은 수행하지 않는다.

## 손실 차단의 의미

10%는 감지 후 주문을 차단/청산하는 기준이며 체결 손실의 보장 상한이 아니다. 가격 급변·체결 지연은 기준 초과를 일으킬 수 있다. [SEC 주문 설명](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders).
