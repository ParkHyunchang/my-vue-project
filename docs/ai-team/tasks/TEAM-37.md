## 관찰 결과

- 확인한 기본 화면의 문서 가로 넘침이나 주요 영역 겹침 없음. 긴 실제 콘텐츠·모바일 카드·데스크톱 표 전환 정상. 320px 메뉴도 화면 안에 들어옴.
- 모바일 구독 추가 및 사용자 생성 모달에서 하단 버튼이 넓은 형태 대신 작은 너비로 가운데 쌓임. 닫기/취소 및 본문 스크롤은 가능하며 기능 차단 수준의 잘림은 확인하지 못함. 격리 검사와 운영 외부 CSS 적용 차이의 영향을 추가 조사할 필요가 있음.
- 비로그인 상태의 최초 홈 직접 진입이 로그인 화면으로 이동함. 로그인 화면의 홈 링크를 클릭하면 공개 홈 열림. 기존 초기 인증/refresh 문제와 일치하는 운영 재현이며 이번 스타일 변경의 신규 회귀 여부는 단정하지 않음.
- 홈의 프로젝트 두 개 '사이트 보기' 링크가 이전 :3100 주소를 가리킴. 현재 운영 주소 :3101과 불일치. 앞선 배포 점검에서 :3100 연결 거절을 확인함.
- 주식 화면에 일부 시세/환율 조회 실패 안내와 미확인 값 표시가 나타남. 화면 배치 문제와 별개의 데이터 조회 이슈. 주문/계좌 설정을 건드리지 않음.
