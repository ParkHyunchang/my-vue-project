# TEAM-27 승인 기준을 유지한 추가 전략 연구

- 시작일: 2026-11-23. 상태: 연구·독립 검증 완료, 신규 후보 미채택·운영 미적용.
- 요청: 다른 전략을 추가 탐색·검증하되 주문 가능 현금과10% 손실 차단, 기존 승인 기준을 유지하고 운영에는 적용하지 않는다.
- 범위: 별도 오프라인 연구 코드·실제 보관 시장자료·재현 가능한 결과와 독립 감사. 기존 연구실/Java 승인 연결의 고정 코드·허용 버전과 운영 설정은 변경하지 않는다.

## 역할과 인수 조건

- 총괄/기획: 기준 고정, 문헌 확인, 결과 비교·기록. 화면 변경이 없어 디자인 구현은 생략한다.
- 개발 research27: `tools/team27_research.py`, `team27_test.py`, 사전선언과 결과. 결과를 보기 전에 후보와 규칙을 고정하고 탈락 결과까지 남긴다.
- 독립 검증 audit27: 별도 감사 코드와 결과. 비용·현금·차단 이력·미래 자료·기간별 기준을 검토한다.
- 과거 승인 조건은 3기간×편도10/25bps 모두 연환산10% 이상·낙폭10% 이하·영구 차단/미청산 없음이다. 기존 전진 관찰60개 신규 거래일·20체결과 상대성과 조건도 완화하지 않는다.
- 신규 후보의 과거자료를 전진 실적으로 바꾸지 않는다. 이번 연구로 즉시 승인 가능한 후보가 생긴다고 보장하지 않는다.
- 기존 원장을 재사용하고 비레버리지·정수수량·현금 한도·매도대금 결제 지연·10% 차단을 유지한다. 새로운 전략은 별도 연구 단계이며 기존 실계좌 허용목록에 추가하지 않는다.

공개 논문의 수익률을 이 프로젝트 성과로 인용하지 않는다. 보유한 4개 ETF 자료에 맞춘 별도 변형이며 논문 그대로의 재현이 아니다. 반복 탐색에 의한 과적합 가능성이 있으므로 과거 통과와 실제 승인 적격을 구분한다.
