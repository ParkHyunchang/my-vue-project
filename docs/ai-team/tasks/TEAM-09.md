- 시작/갱신일: 2026-11-18

- 기준 커밋: frontend ccbac44, backend 64998bf. 기존 문서/격리 테스트 변경 보존.

## 기획 및 완료 기준

대상은 혼자 사용하는 생활·자산 관리 사이트다. 전면 디자인 변경, 다중 사용자 정책, 운영 배포는 제외한다.

1. Todo 일괄 삭제는 확인창에서 제시한 필터 결과 ID만 삭제한다.
2. 기록 사진 제거는 편집 취소/저장 실패 시 원본을 보존하고 저장 성공 후 파일을 정리한다.
3. 일기 분석 응답은 다른 일기 선택/삭제 대상을 바꾸지 않는다.
4. 시세 실패는 마지막 정상 가격과 실패 상태를 유지하며 미조회 금액을 손실 0원으로 표시하지 않는다.
5. 일기 한국 날짜, 미저장 이동 확인, 저장 후 선택 유지.
6. Todo/구독 저장 중 중복 제출 방지, 실패 시 재시도 가능.
7. 여행 결과/채팅/저장은 생성 당시 입력의 목적지·기간과 일치.
8. 평가금액 정렬은 같은 통화로 환산하여 비교.

## 담당과 계약

- 총괄/개발: TimelineFormModal, history/dating 페이지, timeline API/composable, PlannerPanel, 전용 테스트/작업 기록.
- 기획/개발 에이전트: diary 및 전용 API/날짜/테스트.
- 디자인/개발 에이전트: stock 컴포넌트, pricing/stats 및 전용 테스트. 기존 다크·골드 스타일 유지.
- 검증/개발 에이전트: Todo FE/BE, subscription, DeleteModal busy 및 전용 테스트. 구현 후 상호 검토.
- Todo: GET /api/todos/completed/preview (q/priority/category) → {ids,count}; DELETE /api/todos/completed {ids} → {deleted}. 누락 ID는 400으로 전체삭제 방지. 기존 인증/권한 유지.
- 사진: 기존 저장/미디어 API 유지. 저장 성공 응답 후 별도 삭제 요청. 파일 정리 실패는 저장 성공과 구별해 안내하며 원본 파일 보존을 우선한다.
- 여행: 기존 API 유지, 생성 요청 시 입력 복사본을 결과와 함께 유지.

| 미검증 | 8개 전체의 브라우저 E2E, 실제 AI/시세/환율/운영DB, 운영 MySQL·배포. 일기 분석 race 및 미저장 취소는 컴포넌트 테스트로 검증 |

- 일기: 한국 날짜, 저장 응답 선택 유지, draft 이동/route/beforeunload 보호. 늦은 분석은 해당 ID의 분석 필드만 갱신.
- 사진: 편집 중 제거는 로컬 상태만 변경. 저장 실패/취소 시 원본 유지. 저장 성공 후 중복 경로를 제거하고 파일 정리. 정리 실패는 저장 성공과 별도로 경고하며 참조 없는 파일이 남을 수 있음(데이터 보존 우선).
- 시세: 최초 실패 null/계산대기, 이전 값 stale/부분실패 표시, 모든 조회 성공시에만 전체 갱신시각 변경. 원화 환산 정렬과 누락값 후순위.
- 여행: 요청 시 입력 복사본을 만들어 결과/채팅/일정·버킷리스트 저장에 사용.
- Todo/구독: 저장 중 폼 잠금과 요청 guard, 오류 후 재시도 가능.
- 테스트 작성 중 mock/Teleport fixture 문제를 수정하고 전체 재검증 통과. 초기 동시 Maven 컴파일 경합으로 브라우저 harness 컴파일이 실패했으나 검사 종료 후 단독 실행 성공.
- 브라우저는 기본 샌드박스에서 loopback 접근 시간초과하여, 기존 외부연결 차단 harness 그대로 승인된 로컬 실행에서 검증. 종료 후 해당 테스트 서버 중단.
- 증거: [데스크톱](../evidence/team09-diary-desktop.jpg), [모바일](../evidence/team09-diary-mobile.jpg). 외부 CDN 차단으로 운영 스타일과 일부 차이 가능.
- 운영 미배포. Todo 계약 변경은 백엔드 먼저 배포해야 하며, 구 프론트 전체삭제는 400으로 안전하게 거부된다.
- DB 스키마 변경 없음. 운영 데이터/외부 AI/실거래를 사용하지 않는다.
