## 브라우저 관찰

- 전용 주소 `http://127.0.0.1:13110`, 실제 `KiwoomUsAutoTrade.vue`와 위험 패널 및 앱 CSS를 사용했다. Vue 전체 라우터/인증/실제 Spring 서버 통합 검증은 아니다.
- `scripts/isolated-us-risk.cjs`는 환경변수 허용목록·dotenv 로딩 비활성·127.0.0.1 전용 바인딩으로 실행한다. axios는 메모리 mock으로 대체하며 CSP connect-src none과 fetch/XHR/WebSocket 차단을 사용한다. 실제 계좌 활성/주문은 없다.
- 실제 브라우저에서 초기 동의 전 활성화 비활성, 두 동의 후 활성화 가능, 활성화 후 신규매수 중지 유지, 모의 입출금 참조/금액/동의 제출, 모의 신규매수 시작/중지 전환을 확인했다.
- stale(90초 경과), risk API 실패, 계좌 동기화 불명, 10% 손실 잠금 모두 신규매수 시작 비활성 확인. 오류 상태는 누락금액을 0으로 표시하지 않았다.

## 시장자료 검증

공개 실제 일봉 12종×2074거래일(24,888행) 원본/변환값/해시 대조 완료. 생산 신호 함수를 격리 어댑터로 호출해 20,230개 신호를 내보냈다. Java 어댑터 2개 테스트 통과. 조정가격 부동소수점 오차 4행은 상대오차1e-10 이하에서만 고저가 범위를 보정하며 원본은 보존했다.

별도로 Yahoo Finance 배포 S&P 500 총수익 지수 `^SP500TR` 2074행을 확보하여 동일기간 지수와 비교했다. SPY 조정가격 비교도 보조자료로 보존한다. 공식 지수 소유자의 직접 데이터 피드는 아니며 공개 배포 시계열이다. [자료 출처](https://finance.yahoo.com/quote/%5ESP500TR/history/).

가상 원금 $10,000, 기존 실보유 미반영, 각 구간 첫 거래일 종가를 기준점으로 둔다. 다음 날 시가 체결, 비용 차감, 동일 신호·고정 설정으로 계산했으며 결과를 본 뒤 튜닝하지 않았다. 서버 entity 기본값(종목당10%,3종목)과 기존 화면 추세 시작값(25%,4종목) 두 설정을 비교했다. 운영 DB의 실제 저장 설정은 조회하지 않았다.

### 해석 범위

실제 생산 신호 함수는 재사용했지만 현재 전략 전체의 수익률은 아니다. 고정 생존 대형주10종목 표본, 당일 종가의 호가 대용값, 다음 날 시가 전량체결, 배당/분할 조정 가상 소수단위를 사용했다. 당시 지수 구성/상장폐지/호가/거래대금 순위/재무정보/장중 거래량·실제 체결을 재현하지 않았다. 상대강도 단순 순위는 실전 복합점수와 다르며 일일3% 신규매수 중단도 재생하지 않았다. 현금 이자·세금·환율은 반영하지 않았고 종료 보유는 시가평가하므로 미실현 청산비용은 제외했다. 2024~2025 별도 초기화는 독립 OOS 검증이 아니다.

이 제한적 검증에서 목표 초과수익을 뒷받침하는 근거는 얻지 못했다. 실전 운영으로 수익 목표가 달성됐다고 표시하지 않는다.
