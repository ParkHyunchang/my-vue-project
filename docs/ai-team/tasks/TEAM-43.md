## 구현·계약

- `/stock`은 ADMIN에게 국내/미국 자동매매만 표시한다. 기존 수기·시장 정보·삼성/신한 안내·별도 계좌 조회는 진입 화면에서 제거했다. 그 하위 컴포넌트를 마운트하거나 수기 API를 자동 요청하지 않는다.
- `market=US`는 미국, 나머지는 국내 기본값이다. 기존 `tab` 링크는 유효하게 열리고 시장 전환은 확정된 라우트에 따라 적용한다. 뒤로가기·앞으로가기·새로고침을 지원한다. 비관리자는 안내만 보며 거래/삭제 컴포넌트가 마운트되지 않는다.
- ADMIN 자기 계정의 `GET /api/portfolio/manual-records/summary`로 stock/general/isa/irp/accountHoldings/accounts/total 개수를 제공한다. `DELETE /api/portfolio/manual-records`, body `{confirmation:"DELETE_MANUAL_RECORDS"}`가 일치할 때 해당 사용자의 수기 6개 테이블 자료만 단일 트랜잭션으로 삭제한다. 대상 사용자 ID를 요청으로 받지 않는다.
- FE는 하단의 접힌 '이전 수기 기록 정리'를 펼쳐야 개수를 읽는다. 유효한 종류별 개수와 합계가 일치해야 삭제를 허용하며 확인 체크·중복 클릭 방지·삭제 결과 재조회를 제공한다. 오류 후에는 남은 기록을 재조회하도록 안내한다.
- 기존 수기 화면 파일/API는 삭제하지 않았지만 주식 페이지에서는 사용하지 않는다. 예전 브라우저 localStorage 원본은 사용자 식별이 없는 자료가 포함돼 있어 임의 제거하지 않는다. 자동 가져오기/화면 노출은 하지 않는다.
