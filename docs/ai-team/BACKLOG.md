## TEAM-09 — 개인 사용 오류 1~8 수정

- 사용자 승인: 2026-11-18, 개인 사용 기준 검토 목록 1~8 전체.
- 상태: 로컬 구현·검증 완료. [작업 기록](tasks/TEAM-09.md). 운영 미배포.
- Todo 삭제 범위, 사진 삭제 시점, 일기 분석·초안·날짜, 시세 실패, 중복 저장, 여행 조건, 환산 정렬.

## TEAM-01 — 우선 시작 업무

- 로컬 테스트 DB, 외부 API 대역, 국내/미국 자동매매·스케줄러 비활성 조건을 확인해 실행법을 문서화한다. 각 설정이 실제 코드에서 효력을 갖는지 검사한다.
- 현재 백엔드 Mockito attach 문제를 재현하고 원인을 분리한다. 적합한 로컬 또는 CI 환경에서 전체 테스트 결과를 확보한다.
- 완료 기준: 비밀 값 없는 실행 안내, 운영 연결 없이 재현 가능한 검증, 전체 결과와 제한 기록. 임의로 테스트를 제외하거나 skipTests로 통과시키지 않는다.

## TEAM-02 — 자동 검사

- PR 및 배포 이전 검사에서 프론트 lint/Jest/build, 백엔드 격리 테스트와 스타일 검사를 실행한다.
- PR 검사에는 NAS/운영 DB/거래 비밀을 요구하지 않으며 배포 단계가 실행되지 않아야 한다.
- TEAM-01에서 확인한 기존 제품 Java 5개 파일의 Spotless 위반을 좁은 포맷 수정으로 해소하고, 전체 verify를 통과시킨다. 격리 guard의 JDK 21 조건도 CI에 명시한다.
- 완료 기준: 테스트 실패 시 배포 단계로 넘어가지 않음, 기존 main 배포 경로 유지, 실제 CI 실행 결과 기록. 워크플로 작성만으로 CI 통과라고 하지 않는다.

## TEAM-03 — 공통 접근성

- Navbar 모바일 메뉴·사용자 메뉴에 버튼 의미와 열림 상태 제공. Modal 제목 연결, dialog 의미, 초기 포커스, Tab 순환과 닫은 뒤 복귀 지원.
- 완료 기준: Enter/Space/Tab/Shift+Tab/Escape 조작, busy/closeDisabled 유지, 390px·1280px에서 사용 가능. 실제 브라우저 관찰 결과 기록.

## TEAM-04 — 일기 목록 상태

- 첫 사용자 빈 목록, 로딩, 조회 실패, 재시도 성공을 서로 다른 상태로 표현한다.
- 완료 기준: API 실패 시 빈 목록 안내를 성공 화면처럼 표시하지 않음, 재시도로 정상 복구, 중복 요청 방지, 상태별 UI 및 회귀 검증.

## TEAM-05 — 인증 흐름

- 보호된 화면에서 로그인 후 원래 내부 경로로 복귀한다. 목적지가 없거나 허용되지 않으면 안전한 기본 화면으로 이동한다.
- 완료 기준: 새로고침/만료/직접 URL 진입, query 보존, 외부 URL 리디렉션 거부, 권한 없는 경로 처리 검증.

## TEAM-06 — 제품과 권한 기준

- GUEST/USER/PREMIUM/ADMIN별 공개 홈, 개인 도구, 관리자 화면과 직접 API 접근 기대 결과 작성.
- 서버 메뉴 API 실패 및 인증 복원 실패 시 동작을 포함한다. 현재 운영 DB의 역할 설정은 별도 확인 항목으로 둔다.
- 완료 기준: 권한별 정상·거부 사례와 사용자 데이터 분리 검증 근거. 금융 제어는 백엔드 저장소 루트의 `KIWOOM_UI_CONTROL_CHECKS.md`를 참고하고 실제 주문 없이 테스트한다.

## TEAM-07 — Todo 데이터 분리

- [실제 검증](tasks/TEAM-01-BROWSER.md)에서 A의 Todo를 B가 조회·수정할 수 있음을 확인했다. 개인 도구인지 공유보드인지 정책을 정하고 기대 권한을 명세한다.
- 개인 도구 기준 완료 조건: 생성 시 소유자 설정, 목록/ID 조회/수정/삭제/완료 전체 삭제/카테고리 집계의 사용자 범위 제한, 기존 소유자 없는 데이터 처리 방안, 서로 다른 두 사용자로 허용·거부 통합 테스트.
- 현재 P1은 개인 도구 기준이다. 정책 합의 전 운영 데이터를 임의 배정·삭제하지 않는다.

## TEAM-08 — 공개 홈 진입 유지

- 비로그인 공개 홈 새로고침 시 초기 인증/refresh 401 때문에 로그인으로 강제 이동하는 문제를 수정한다.
- 완료 기준: `/`와 공개 콘텐츠의 비로그인 직접 진입·새로고침 유지, 보호 경로의 로그인 유도 유지, 로그인 중 세션 만료·동시401 refresh 기존 동작 회귀 검증.
